# Foodpanda POS Portal

## Project Overview

The **Foodpanda POS Portal** is a web-based Point of Sale and database management project developed using HTML, CSS, JavaScript, Oracle Database, Oracle APEX, and Oracle REST Data Services.

The portal provides separate pages for managing and viewing business records such as customers, employees, suppliers, shippers, orders, and products. It communicates with an Oracle database through RESTful APIs to retrieve, insert, update, and delete records.

This project has been developed as a practical learning experience to understand frontend development, database operations, REST API integration, authentication, session-state management, and user-friendly application design.

## Features

The project currently includes or is being developed to include the following features:

- User login validation
- Login-state and username management
- Navigation between multiple portal pages
- Customer record management
- Employee record management
- Supplier record management
- Shipper record management
- Order management
- Product listing and product details
- Oracle ORDS RESTful API integration
- Database insertion, retrieval, modification, and deletion
- Confirmation boxes before destructive actions
- Success, warning, and error messages
- Input-field validation
- Activity logging for database operations
- Automatic timestamps for activity logs
- Dynamic product table generation
- Product detail card display
- Logout functionality
- Responsive and user-friendly interface improvements
